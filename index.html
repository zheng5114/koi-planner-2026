📤 导出到苹果日历

导出全部日程为 .ics 文件。iPhone/Mac 上打开文件即可一键加入「日历」App；电脑版日历（Outlook 等）同样支持。之后可在日历中订阅或手动同步。

📝 导出到苹果备忘录

把你的目标、复盘、最近记录整理成一条结构化文本，复制后粘贴到 iPhone 备忘录（长按 → 粘贴）。

💾 备份与恢复

📱 手机推荐用「复制备份文本」→ 粘贴到备忘录或发给自己微信，最稳妥；电脑上用「导出 JSON 文件」更方便。导入时点「导入备份」选中之前保存的文本文件即可。
🔄 同步方法：在手机 App 点「📋 复制备份文本」→ 微信发给自己 → 在电脑这里粘贴并点导入；反过来也一样。导入会覆盖本机数据（建议先点「复制备份文本」留存当前数据）。

📱 添加到主屏幕

iPhone：Safari 打开本页 → 分享按钮 → 「添加到主屏幕」，即可像 App 一样全屏使用。
电脑：浏览器菜单 → 安装/创建快捷方式。在线部署后手机电脑数据各自独立，重要数据记得定期备份互通。

📱 iPhone / iPad 同步步骤

1. 用 Safari 打开本 App 并点击导出（文件会出现在下载中）
2. Safari 地址栏旁点「下载」图标 → 点刚下载的 .ics 文件
3. 系统自动跳转「日历」App → 选择要加入的日历（建议新建一个"规划本"日历）→ 确认
✅ 全部日程一键进入苹果日历，可收提醒通知

💻 Mac 同步

双击 .ics 文件 →「日历」App 弹出导入窗口 → 选择日历 → 好。若 iCloud 已登录，日程会自动同步到 iPhone。

🖥 Windows（Outlook / 日历）

双击 .ics 文件，Outlook 会提示添加；或在 Windows「日历」App 设置 → 添加日历 → 从文件导入。
💡 小提示：.ics 是"导入式"同步——App 里日程更新后，需重新导出导入一次（同日期事件会更新而非重复）。
