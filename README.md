# 锦鲤紫 · 2026 规划本 App

基于《锦鲤紫 ElenaLin Planner 2026》结构打造的网页应用，电脑浏览器和 iPhone Safari 均可使用（iPhone 可"添加到主屏幕"当 App 用）。

## 功能
- 🎯 年度目标：7 大人生领域 + 季度分解 + KPI + 习惯化，含 SWOT 和梦想版
- 📅 季度规划与反思、月历（点击日期加日程）与月度复盘（目标/已完成/未完成/自省/学到的事）
- 📐 周计划（Top 3 + 每日安排 + 周末回顾）
- ☀️ 每日三栏：To Do / 学到 / 感悟 + 一日三问
- ⬛ 决策黑箱：7 问决策引导
- 📚 学习计划打卡
- 🤖 AI 生活教练：填任意 OpenAI 兼容 API（OpenAI/DeepSeek/智谱/硅基流动等）即可复盘近 7/30 天、月度分析、季度评估、自由对话，输出进展分析与生活建议
- 📤 苹果日历：导出 .ics（全部/本月）一键导入；单个日程可一键唤起 iPhone 日历
- 📝 苹果备忘录：一键生成结构化文本并复制粘贴
- 💾 数据存本机 localStorage，支持 JSON 备份/恢复

## 使用
直接打开 index.html，或部署为静态站点后在手机上访问。
AI 功能：进入「🤖 AI」页 → 填接口地址（如 https://api.deepseek.com/v1/chat/completions）、模型名、API Key。
